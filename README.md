## 🛠 Engineering Philosophy

I don't just write code; I design systems. Here is how I approach development:

* **Database First:** A robust schema (Prisma/SQL) prevents 90% of bugs before they happen.
* **Infrastructure as Code:** I containerize applications (Docker) to ensure "it works on my machine" means "it works in production."
* **Performance by Design:** Implementing **Redis Pub/Sub** for real-time scaling and **Nginx** for load balancing.
* **Monorepo Architecture:** Sharing types and utilities between Frontend and Backend to ensure strict type safety across the stack.

## 🚀 Production-Level Projects

### 🏦 **[Project Name: FinTech / Banking System]**
> *A distributed banking architecture focusing on atomicity and concurrency.*

* **Architecture:** Monorepo (Next.js + Express + Postgres).
* **Key Challenge:** Handling concurrent transactions without double-spending.
* **Solution:** Implemented **Pessimistic Locking** in Postgres and used a **Message Queue** for async notifications.
* **DevOps:** Fully automated Docker image builds via GitHub Actions.

### 💬 **[Project Name: Real-time Chat Cluster]**
> *A scalable WebSocket infrastructure for live communication.*

* **Architecture:** Node.js WebSocket Server + Redis Adapter.
* **Key Challenge:** Scaling WebSockets beyond a single server instance.
* **Solution:** Built a **Redis Pub/Sub layer** to broadcast messages across multiple Docker containers.
* **Performance:** Capable of handling connection draining and auto-reconnection.
